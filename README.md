# Control Systems — Exam Prep

Interactive study tool for a control-systems course. Practice each lesson's test
with progressive hints, worked solutions, and math crash courses with randomized
drills.

**Live site:** https://sputnikboi.github.io/control-systems-prep/

## Contents

- **Lesson 10 — Observability, Observers & Observer-Based Control**
  - 4 exam questions with step-by-step hints and full worked solutions
  - Crash courses: matrix multiplication, determinant & rank of 2×2, eigenvalues of 2×2
  - Each crash course has a randomized practice generator (New problem → Check → Show steps)

It's a single self-contained `index.html` — no build step, no dependencies.
Open it directly or serve the folder statically.
